# LEOPA SUPPLY website

Static website with stock construction photographs and a project-enquiry draft builder. No build step or server is required. Open index.html locally, or publish the repository's main branch and root folder using GitHub Pages.

The form prepares a WhatsApp or email message for the visitor to review and send. It does not collect or store submissions. Save contact downloads Blessing Leopa's supplied vCard. The existing digital business card has a separate GitHub Pages address.

Stock image sources and licences are recorded in photo-credits.html. These images are explicitly illustrative, not presented as the company's projects. Replace them with approved real project photos when available.

The NHBRC statement is company supplied and not independently verified. No private certificate address, director ID or tax information is included.

To update: edit index.html, styles.css or site.js and commit/upload the replacement files. Keep the filenames and relative paths unchanged.
